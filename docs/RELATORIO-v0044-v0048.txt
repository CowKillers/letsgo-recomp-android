- **Resultado no aparelho**: DISPAROU! `[font-watch] WRITE DETECTED at 0x729c3aa92a (pc=0x7cfa29d19c)`
- **Conclusão**: A rasterização do Beluga FUNCIONA. O problema está depois (upload/draw ou atlas errado).

## Como compilar
```bash
cd ~/workspace/letsgo-port
export PATH=/usr/bin:$PATH
# 1. Gerar código (se src/generated-aarch64/ não existir):
#    make gen ARCH=aarch64
# 2. Build:
bash build-gamelib.sh
bash build-runtime.sh
bash link-runtime.sh
bash build-importer.sh
rm -rf build/apk
bash build-apk.sh
```
- Assinar SEMPRE com `~/workspace/dr2cw-android/apk-test/debug.keystore` (alias `androiddebugkey`, senha `android`)
- Incrementar `versionCode` em `apk/AndroidManifest.xml` a cada build (usar `date +%s`)
